# Decifra.IA

Jogo educacional de terminal para praticar logica matematica e raciocinio computacional.

Desenvolvido por Squad 05 como Projeto Integrador 2P - E5 no CESAR School.

Implementado em **C** na Unidade 1 e **Haskell** na Unidade 2.

## Estrutura do projeto

```
decifra-ai-e5/
├── src/          # Codigo-fonte em C (Unidade 1) e Haskell (Unidade 2)
├── include/      # Headers .h dos modulos em C
├── docs/         # Documentacao tecnica e decisoes de arquitetura
├── tests/        # Testes de unidade
└── Makefile      # Compilacao do projeto em C
```

---

## Como compilar e rodar

> Instrucoes de build serao adicionadas em PI2-56 apos a configuracao do Makefile (PI2-54).

**Pre-requisitos:** gcc, make

```bash
git clone https://github.com/guialveess/decifra-ai-e5.git
cd decifra-ai-e5
make
./decifra
```
